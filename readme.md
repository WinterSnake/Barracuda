# Barracuda
This is the full suite of tools for the Barracuda password manager. Includes a REPL and Kivy client in Python, a web server built in Rust, and Javascript extensions for chrome and firefox.

## Supported Frontends
- [ ] (Python) REPL
- [ ] (Python) Kivy GUI
- [ ] (Javascript) Chrome Extension
- [ ] (Javascript) Firefox Extension

## Supported Backends
- [ ] SQLite3
- [ ] MySQL
- [ ] Postgres
